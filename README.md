# ElRagel El3naaab Dice
Welcome to **ElRagel El3naaab Dice**!

I love _El Ragel El 3nab_ , and I strongly believe that adding a little humor makes learning to code a lot more fun. This project is a small, funny Flutter task designed to practice state management and logic while having a good laugh.
## How It Works

It's simple! You throw two dice, and the app keeps track of your luck:

- **Total Throws:** Checks how many times you've rolled the dice.
    
- **Wins:** You score a win every time the two dice match (show the same number).
## To Try it

```
git clone https://github.com/sandosaa/ElRagl-El3nab-Dice.git
cd ElRagl-El3nab-Dice
flutter run
```
